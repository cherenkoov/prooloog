# Prooloog

Дэшборд проектов: мини-приложение Telegram, бот и база данных на своём сервере.

Страница дэшборда (`public/index.html`) — та же самая, что работает внутри Claude. На сервере ей помогает
небольшой адаптер (`public/shim.js`): он входит через Telegram и заменяет платформу Claude запросами к этому серверу.

## Что внутри

| Файл | Зачем |
|---|---|
| `src/server.js` | Веб-сервер: страница, API данных, живое обновление, вебхук Telegram |
| `src/db.js` | Postgres: хранилище документов (коллекция + id → JSON) и служебные таблицы |
| `src/auth.js` | Вход через Telegram Mini App, сессии, роли: владелец, редактор, зритель |
| `src/bot.js` | Бот: открыть дэшборд, вход в браузере, ответы клиентов на ревью, копии данных |
| `src/realtime.js` | Живое обновление открытых экранов |
| `src/ai.js` | Ответы Claude внутри дэшборда. Включается ключом `ANTHROPIC_API_KEY` |
| `public/shim.js` | Адаптер страницы к серверу |
| `render.yaml` | Описание развёртывания на Render |
| `test/` | Проверки сервера и локальная песочница |

## Правило про ответы клиентов

Бот только сохраняет ответ клиента и привязывает его к проекту. Сам проект (задачи, майлстоуны, статус)
меняется после ревью владельца в дэшборде. Сервер это правило не обходит.

## Бот

- `/start` — открыть дэшборд; `/login` — одноразовая ссылка для входа в обычном браузере
- переслать сообщение или голосовое клиента → выбрать проект → сообщение ждёт ревью
- «от имя, проект: текст» — то же одной строкой; можно сначала «от имя, проект», потом само сообщение
- любой другой текст — во входящие или как ответ клиента
- `/invite @имя editor|viewer`, `/members`, `/remove @имя` — доступ для других людей
- `/backup` — копия всех данных файлом; файл с подписью `/restore` — восстановить из копии

Раз в 7 дней бот сам присылает владельцу свежую копию данных (`BACKUP_DAYS`, 0 — выключить).

## Переменные окружения

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | Строка подключения к Postgres |
| `BOT_TOKEN` | Токен бота от @BotFather |
| `OWNER_USERNAME` | Имя пользователя Telegram, которое станет владельцем при первом `/start` |
| `OWNER_ID` | Вместо имени можно сразу указать числовой id владельца |
| `SESSION_SECRET`, `WEBHOOK_SECRET` | Случайные строки, Render создаёт их сам |
| `APP_TZ` | Часовой пояс по умолчанию, `Asia/Tbilisi`. Пояс, выбранный в настройках дэшборда, важнее |
| `ANTHROPIC_API_KEY` | Необязательно. Включает ответы Claude в дэшборде (платно, по использованию) |
| `AI_MODEL` | Необязательно. Модель Claude, по умолчанию `claude-sonnet-5-5` |

## Перенос данных из версии в Claude

1. В дэшборде внутри Claude: кнопка «Настройки» → «Скопировать все данные».
2. В дэшборде на сервере: кнопка «Настройки» → «Загрузить копию» → вставить текст → «Заменить данные этой копией».

## Локальный запуск и проверки

Нужны Node 22 и Postgres.

```bash
npm ci
TEST_DATABASE_URL=postgres://user@127.0.0.1:5432/prooloog_test npm test   # проверки сервера
DEV_DATABASE_URL=postgres://user@127.0.0.1:5432/prooloog_dev node test/dev-server.js   # песочница на порту 18081
```

Проверки и песочница используют подставные Telegram и Claude API: настоящие запросы наружу не уходят.

## Чего пока нет

- расшифровки голосовых: аудио сохраняется и проигрывается, текст вписывается вручную;
- отправки постов в Metricool с сервера: текст варианта копируется и публикуется вручную;
- подключения внешних календарей (Google, Apple, Notion).


## Claude: ответы, вопросы боту, коннектор

**Ответы Claude в приложении и в боте.** Нужен ключ API из консоли Anthropic. В Render: сервис `prooloog` → Environment → добавить `ANTHROPIC_API_KEY`. После этого работают «Разобрать с Claude», чат в комментариях, варианты постов и команда бота `/ask вопрос`: Claude видит проекты, задачи, события и отвечает в Telegram. Данные он не меняет.

**Расход.** Сервер считает каждый свой запрос к Claude: токены на вход и выход и оценку стоимости по прайсу модели (`AI_PRICE_IN`, `AI_PRICE_OUT` в долларах за миллион токенов меняют прайс). Смотреть: «Бюджет» → «Подписки» → блок Claude, или `/usage` у бота. Точная сумма остаётся в консоли Anthropic.

**Коннектор для Claude.** Команда `/connect` у бота выдаёт адрес вида `https://…/mcp/<ключ>`. В Claude: Customize → Connectors → Add custom connector, название `Prooloog`, вход «No sign-in». После этого Claude в чате читает данные дэшборда, сохраняет сообщения клиентов на ревью и синхронизирует данные со страницей внутри Claude (кнопка «Синхронизировать с сервером» в «Данных»). `/connect new` выдаёт новый адрес и отключает старый. Адрес открывает все данные: не пересылать.

## Напоминания о событиях и созвоны

В карточке события задаются правила «за сколько до начала» (до пяти) и ссылка на созвон: Zoom, Google Meet или любая другая. Постоянная ссылка платформы запоминается и подставляется в следующие события. Бот шлёт владельцу напоминания по правилам, а если у события есть ссылка, за 5 минут до начала присылает и её. Время считается по часовому поясу приложения; событие без времени считается начинающимся в 09:00.

«Ссылка для участника» в карточке события ведёт в бота (`https://t.me/<бот>?start=ev_…`). Участник нажимает «Старт», выбирает свои напоминания и тоже получает ссылку на созвон за 5 минут. Доступа к дэшборду это не даёт.

**Важно про бесплатный тариф Render.** Веб-сервис засыпает через 15 минут без обращений, и пока он спит, напоминания не уходят: проверка идёт раз в 30 секунд только у работающего сервера. Надёжно работает на платном тарифе или при внешнем «будильнике», который раз в 10 минут открывает `/healthz`.
